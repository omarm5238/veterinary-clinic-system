# Veterinary Clinic Management System

## Overview

This project is a web-based system designed to improve how veterinary clinics manage appointments and communication between doctors and pet owners.

The system brings booking, messaging, and workflow management into one platform to reduce confusion and improve efficiency.

---

## Features

* Role-based access (Customer, Doctor, Admin)
* Real-time appointment booking
* Structured appointment lifecycle (Pending, Confirmed, Completed, Cancelled)
* Real-time chat between doctor and customer
* Emergency handling feature
* Firebase-based real-time data synchronization

---

## Technologies Used

* Flutter Web
* Firebase Authentication
* Cloud Firestore
* Firebase Hosting (for deployment)

---

## System Roles

### Customer

* Register and login
* View available appointments
* Book appointments
* Chat with doctor

### Doctor

* Login using doctor credentials
* Manage availability
* Confirm appointments
* Chat with customers

### Admin

* Manage system users
* Access system controls

---

## How to Run the Project

1. Clone the repository:

```
git clone https://github.com/omarm5238/veterinary-clinic-system
```

2. Navigate to the project folder:

```
cd veterinary-clinic-system
```

3. Install dependencies:

```
flutter pub get
```

4. Run the project:

```
flutter run -d chrome
```
